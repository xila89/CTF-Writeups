# CTF Write-Ups

Investigation-style write-ups for cybersecurity CTFs and competitions. 

Rather than documenting only the successful path to the flag, these writeups focus on investigative methodology, evidence, failed hypotheses, technical findings, and the reasoning behind each pivot.

### Sisterhood of the Traveling Packets
Ransomware infrastructure investigation involving Tor, exposed victim data, artifact analysis, API enumeration, broken access controls, and credential discovery.
